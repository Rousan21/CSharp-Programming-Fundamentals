# C# Programming Fundamentals

A collection of introductory C# coursework that documents my early progression through programming fundamentals and object-oriented programming.

## Labs

### Lab 1 — Programming Basics

Practice with:

* Variables and data types
* User input
* Type conversion
* Arithmetic operators
* Constants

### Lab 2 — Conditional Logic

Practice with:

* Boolean expressions
* `if` / `else`
* Comparison and logical operators
* `switch` statements

### Lab 3 — Loops and Arrays

Practice with:

* `for` and `while` loops
* `foreach`
* Arrays
* Basic array sorting and manipulation

### Lab 4 — Classes and Objects

Introduction to object-oriented programming through:

* Classes and objects
* Fields
* Methods
* Object state and behavior

### Lab 5 — Inheritance

Practice with:

* Base and derived classes
* Inheritance
* Method overriding
* Polymorphic behavior

## Technology

* C#
* .NET

## About

These labs come from my earlier programming coursework and helped build the foundation I later used when moving into data structures, algorithms, Python, and broader computer science work.

My current development focus is primarily Python, but I've kept this repository to document that earlier progression.
